# Hope Pro - React Tailwind Admin Dashboard

Hope Pro is a React and Tailwind CSS admin dashboard application developed by **Bengal Mobile QA Solution (BMQAS)**, providing developers with everything they need to create a comprehensive, data-driven back-end, dashboard, or admin panel solution.

With Hope Pro, you get access to all the necessary dashboard UI components, elements, and pages required to build a feature-rich and complete dashboard or admin panel. Whether you're building dashboard or admin panel for a complex web application or a simple website, Hope Pro is the perfect solution to help you get up and running quickly.

## Overview

Hope Pro provides essential UI components and layouts for building feature-rich, data-driven admin dashboards and control panels. It's built on:

- React 19
- TypeScript
- Tailwind CSS v4
- Vite

## Installation

### Prerequisites

To get started with Hope Pro, ensure you have the following prerequisites installed and set up:

- Node.js 18.x or later (recommended to use Node.js 20.x or later)

### Setup

1. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

2. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

3. Build for production:
   ```bash
   npm run build
   # or
   yarn build
   ```

## Components

Hope Pro is a comprehensive admin dashboard application built with React.js and Tailwind CSS. It includes:

- Sophisticated and accessible sidebar
- Data visualization components
- Prebuilt profile management and 404 page
- Tables and Charts (Line and Bar)
- Authentication forms and input elements
- Alerts, Dropdowns, Modals, Buttons and more
- Calendar with event management
- Dark Mode support 🕶️

All components are built with React and styled using Tailwind CSS for easy customization.
